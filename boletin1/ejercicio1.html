HTML
HTML (por sus siglas en inglés, HyperText Markup Language, o Lenguaje de Marcado de Hipertexto) es el lenguaje estándar utilizado para crear, estructurar y dar esqueleto a las páginas web.
CSS
CSS (Cascading Style Sheets u Hojas de Estilo en Cascada) es un lenguaje de diseño que se utiliza para definir la apariencia visual y la maquetación de los documentos creados en HTML o XML.
DOM
El DOM (Document Object Model o Modelo de Objetos del Documento) es una interfaz de programación que representa los documentos HTML o XML como una estructura jerárquica de árbol, donde cada etiqueta, texto o atributo es un nodo que los lenguajes como JavaScript pueden leer, modificar, añadir o eliminar en tiempo real.
